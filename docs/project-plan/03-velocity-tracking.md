# Velocity & Progress Tracking

*The tracking system for this plan. Update it whenever you finish a work session.
The point is to map **estimated effort → actual delivered time** so future
estimates get accurate (your personal "velocity"). Early estimates will be off;
that's the process working, not failing.*

## How to use this (2 minutes per session)

1. When you finish a task, fill its **Actual hrs** and flip **Status** to ✅.
2. Each Friday, fill that week's row in **Weekly velocity**.
3. After W2, compute **velocity ratio = actual ÷ planned**. If it's >1.25 (you're
   slower than planned), apply the re-baseline note at the bottom.

Status key: ⬜ not started · 🔄 in progress · ✅ done · ⏭️ cut/deferred
