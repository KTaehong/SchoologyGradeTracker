## Completed

### 1. Manual entry (T2.1, F06) — done
A student can build a class from zero: add a class (name, teacher, weighted or
total points, grading periods), then add, edit and delete categories (weight,
drop lowest) and assignments (score, points possible, due date, excused, extra
credit) from the course screen. Every change is saved on the phone, regrades
immediately and syncs. Deleting a class deletes everything in it; its upcoming
items stay, unfiled, as on the server. Form limits match the Supabase column
limits, so a saved row always syncs.

### 2. Faster startup (unplanned fix)
Expo Go looked frozen at launch when the saved sign-in had expired: the tabs
waited for Supabase to refresh the token, which can retry for ~30 s on slow
or blocked Wi-Fi. Now the tabs open right away from the phone's gradebook and
sync starts when the check finishes ([`48841ec`](https://github.com/KTaehong/SchoologyGradeTracker/commit/48841ec)).
Expo Go troubleshooting steps were added to `mobile/README.md`.

### 3. Apple Developer access → Sign in with Apple + EAS config (this branch)
I now have access to an Apple Developer team as a guest on my teacher's project,
so I used it this week:
- **Sign in with Apple** on iPhone, using Apple's native sheet
  (`expo-apple-authentication`). Supabase checks Apple's ID token directly, so
  no Services ID, signing key or web callback is needed. The app sends Apple a
  hashed one-time code (nonce) so a stolen token can't be reused. Apple gives
  the student's name only on the first sign-in; the app saves it to the profile
  then (otherwise it would stay "Student"). Code: `mobile/src/api/apple-sign-in.ts`,
  `mobile/src/api/auth.ts`, `mobile/src/lib/apple-name.ts`.
- **App IDs:** `com.ktaehong.gradetracker` on iOS and Android, with the
  Sign in with Apple capability in `mobile/app.json`.
- **EAS Build profiles** (`development`, `preview`, `production`) in
  `mobile/eas.json`, and build steps in `mobile/README.md`.
- **Setup steps** for the Apple App ID and the Supabase Apple provider in
  `docs/database/README.md`.
